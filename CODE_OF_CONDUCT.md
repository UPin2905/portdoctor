# Code of Conduct

We want PortDoctor to be a respectful, welcoming project for everyone. Be constructive, assume good intent, and avoid harassment, discrimination, or personal attacks.

Report unacceptable behavior privately through a [GitHub security advisory](https://github.com/UPin2905/portdoctor/security/advisories/new). Maintainers will review reports promptly and may remove content or restrict participation when necessary.
