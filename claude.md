# PortDoctor Development

- The CLI lives in `cmd/portdoctor` and `pkg`.
- The Windows desktop application lives in `portdoctor-ui`.
- Run `go vet ./...` and `go test ./...` from the repository root before contributing.
- Run `go test ./...` from `portdoctor-ui` and `npm run build` from `portdoctor-ui/frontend` when changing the desktop UI.
