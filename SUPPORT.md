# Support

- Use a [bug report](https://github.com/UPin2905/portdoctor/issues/new/choose) for reproducible problems.
- Use a [feature request](https://github.com/UPin2905/portdoctor/issues/new/choose) for improvements and new platform support.
- Use a [private security advisory](https://github.com/UPin2905/portdoctor/security/advisories/new) for vulnerabilities.

Please include the PortDoctor version, operating system, command output with sensitive details removed, and concise reproduction steps.
